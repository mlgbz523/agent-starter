## ADR-001：采用 AGENTS.md 统一工作区顶层指令入口
- **决策日期**：2026-10-05
- **背景现状**：不同 AI 工具（Antigravity、Cursor、Claude Code）各自有 `.cursorrules`、`GEMINI.md` 等私有配置。
- **备选方案**：
  - 方案 A：仅使用私有 `GEMINI.md`
  - 方案 B：使用 Linux 社区发起的开放标准 `AGENTS.md`，并通过软链接/包含兼容 `GEMINI.md`
- **最终决策**：选择 **方案 B**。
- **核心理由**：实现 100% 跨工具跨团队复用，资产不被任何单一商业 IDE 绑定。

## ADR-002：本地 Python 脚本辅助技能搜寻 (skill-curator)
- **决策日期**：2026-10-05
- **背景现状**：让大模型直接抓取网页（如 SkillsMP）寻找 Skill，单页消耗 30,000+ Token，成本极高且多为低质 AI-Slop。
- **备选方案**：
  - 方案 A：大模型直接联网浏览并分析网页
  - 方案 B：纯 Python 3 标准库脚本调用 GitHub API 检索并过滤元数据，大模型只看 200 字摘要做决策
- **最终决策**：选择 **方案 B**。
- **核心理由**：将全流程 Token 消耗压至 1,000 以内（节约 98%），且通过物理拉取杜绝虚假 URL 幻觉。

## ADR-003：采用 Pre-commit 框架与 Conventional Commits 原生门禁
- **决策日期**：2026-10-06
- **背景现状**：单纯靠 Prompt 提醒 Agent “不要传敏感文件、格式规范”，容易因注意力稀释而失效。
- **备选方案**：
  - 方案 A：纯 Prompt 软口头约定
  - 方案 B：在 Git 底层安装 pre-commit 与 conventional-pre-commit 物理钩子拦截
- **最终决策**：选择 **方案 B**。
- **核心理由**：实现 0 Token 消耗的代码级物理安全硬拦截，确保每一笔提交格式符合语义化版本标准。

## ADR-004：彻底剥离 GEMINI.md 别名，确立 AGENTS.md 为唯一真实源
- **决策日期**：2026-10-09
- **背景现状**：经核验 Antigravity 官方文档与运行时探针，引擎已 100% 原生识别 `AGENTS.md` 为第一公民，`GEMINI.md` 仅为旧版遗留别名，保留会导致重复解析。
- **备选方案**：
  - 方案 A：继续保留 `GEMINI.md` 的 `@include` 壳文件
  - 方案 B：彻底清理全局与工作区内的 `GEMINI.md`，仅保留单一真实源 `AGENTS.md`
- **最终决策**：选择 **方案 B**。
- **核心理由**：消除多余解析与上下文开销，保持工程底座极致纯净，实现单一真实源。

## ADR-005：采用 Cloudflare Serverless 构建私有持久化长记忆大脑（Second Brain）
- **决策日期**：2026-10-09
- **背景现状**：长对话下智能体会遗忘关键约定与偏好。Mem0 官方云服务有免费配额限制且依赖第三方闭源平台；用户希望拥有一个独立、持久、带可视化 Web 面板并支持 MCP 协议的私有记忆库，同时不产生云服务器租用费用。
- **备选方案**：
  - 方案 A：购买轻量云服务器自建 Docker + Qdrant + FastEmbed + Node.js 服务
  - 方案 B：利用 Cloudflare 边缘免费基础设施（Workers + D1 + Vectorize + Workers AI）部署开源 `second-brain-cloudflare`，零服务器费用，原生整合 Web UI 和 20 个 MCP 原生工具
- **最终决策**：选择 **方案 B**。
- **核心理由**：
  1. **零成本运行**：充分利用 Cloudflare 永久免费额度（每天 10 万次 Workers 请求、500 万次 D1 读取、每月 3000 万维 Vectorize 查询），个人日常使用占比不到 1%；
  2. **双模整合**：同时具备可视化管理界面（Web UI Dashboard）与 MCP 标准协议接口，在 IDE 与浏览器双端无缝互通；
  3. **国内免翻秒开**：绑定用户自定义域名（`brain.28870721.xyz`），避开默认 workers.dev 域名在国内的 SNI 阻断；
  4. **完全自主掌控**：数据 100% 存储在用户个人 Cloudflare 账户，不依赖第三方闭源 AI 云平台。

## ADR-006：开发习惯经验解耦移入 Second Brain 与宪法级 Recall Hooks 落地
- **决策日期**：2026-10-09
- **背景现状**：本地 `AGENTS.md` 与规则切片中包含大量具体的命令套路（如 Windows PowerShell 的 Git 避坑转义）、微观注释偏好、外部依赖审核指标与数千字节的静态 Markdown 卡片模板。这导致每轮请求携带庞大的静态 Prompt，容易稀释模型注意力并增加响应延迟。
- **备选方案**：
  - 方案 A：继续将所有细节、命令与模板死死焊在本地各个 `.agents/rules/` 文件中；
  - 方案 B：彻底删除所有细节与模板，完全依赖模型自主推断；
  - 方案 C：分层治理——硬门禁（三红线、安全红线、状态机锁、外科手术式修改）坚决留在本地；5 类习惯与长篇模板沉淀至私有 Cloudflare Second Brain；在主宪法中植入 4 行轻量 Recall Hooks 意图路由。
- **最终决策**：选择 **方案 C**。
- **核心理由**：
  1. **零安全风险**：不可逾越的硬门禁 100% 留在本地，保证每轮确定性拦截；
  2. **Prompt 大幅瘦身**：静态规则文件净减少 78 行，模板代码开销降低 75%，有效防止注意力稀释；
  3. **无感精准召回**：通过意图路由锚点在特定动作（选型、探针、环境回滚、卡片排版）前自动触发 `second_brain_recall`，开发者完全无感即可享受高度定制化的经验复用。
