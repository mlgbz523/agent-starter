# 05-PM Interaction Templates

> **使用宗旨**：所有面向 PM 的交互，Agent 必须以“PM 具备业务常识但无技术判断力”为前提，替 PM 准备好全部决策条件。

---

## 模板一：PM 决策卡片 (Decision Card)
*适用场景：方案权衡、分支选择、需求模糊对齐、命中三红线任务呈报。*

```markdown
### 📋 PM 业务决策请求
- **要决定什么**：[用一句话白话概括核心冲突或选择]
- **已保存任务开始前的状态**：还原点编号 [xxx]（随时可说“撤销”回到这里）
- **交接看板状态**：`docs/PROGRESS.md` 中【需要你决定的事】已同步更新
- **拟定验收标准 (PM 白话 3~5 条，就地展示，禁甩链接)**：
  1. [验收项 1：用户在什么场景看到什么效果]
  2. [验收项 2：操作失败或异常时表现]
  3. [验收项 3：数据清空或重置表现]
  4. [验收项 4：刷新或重新开局的持久表现]
- **选项对比**：
  - **选项 A（[名称]）**：耗时 [X] | 额外成本 [无/低/高] | 用户体验 [说明] | 以后改起来容易吗 [是/否]
  - **选项 B（[名称]）**：耗时 [X] | 额外成本 [无/低/高] | 用户体验 [说明] | 以后改起来容易吗 [是/否]
- **可选建议（本次默认不做）**：[若有额外想法单列于此，严禁混入主需求]
- **Agent 推荐**：推荐选项 [A/B]，理由是 [一句话业务理由]。
- **如果你不确定**：默认选 [A/B]（因为它是改动最小、最容易撤销的方案）。
- **最坏情况与撤销手段**：选错了会怎样？[说明最坏后果]；撤销手段：随时说“撤销刚才的修改”，安全还原到任务开始前的还原点。
```

## 模板二：高危操作审批请求卡片 (Approval Request)
*适用场景：命中五大必须点头清单（删数据、改库结构 DDL、上线部署、花钱 API、引入新依赖、高危 Git、改规则）。*

```markdown
### 🚨 高危操作审批申请
- **申请操作**：[一句话说明要做什么]
- **业务影响面**：[会影响到哪些功能、数据或页面]
- **最坏后果**：[如果失败，最严重会导致什么情况]
- **能否安全撤销**：[是/否，说明撤销与还原手段，如执行 down.sql 或恢复备份]
- **Agent 的明确建议**：[建议批准 / 建议拒绝]，理由：[一句话白话说明]
*(注：PM 尚未明确回复前，严禁执行任何实质改动)*
```

## 模板三：交付完成声明三分法 (Three-Column Completion)
*适用场景：功能完成、Bug 修复后的交付汇报，杜绝自说自话与含糊带过。*

```markdown
### 🎯 交付完成声明 (PM 验收看板)

#### 1. ✅ 已验证 (事实可查)
- [功能点 1]：跑过 [测试命令/点击验证]，结果为 [白话结论，如：通过 8/8 项测试 / 点击重开按钮雷区立即重置]。
- [功能点 2]：...

#### 2. ⚠️ 未验证 (明确告知边界)
- [边界点 1]：尚未在 [如手机小屏/极端高并发] 下实测，已知表现为 [说明]。
- [边界点 2]：...

#### 3. ❓ 不确定 (坦诚猜测与风险)
- [潜在疑点 1]：[坦诚指出可能存在的隐患或依赖外部稳定性的地方]。
*(注：不确定就直说不确定，严禁为了显得完成而隐瞒或模糊带过)*
```

## 模板四：熔断受阻与错误报告卡片 (Block Report)
*适用场景：触发 2 次错误熔断停机，将技术报错翻译为 PM 可决策的下一步。*

```markdown
### 🛑 任务受阻停机报告 (已触发二次熔断)
- **卡在哪里**：[一句话大白话，禁止纯丢错误堆栈，如：新加的标记红旗功能和原有的自动翻开逻辑打架了]
- **已尝试过的动作**：[已经尝试过方案 X 和方案 Y，但测试仍然失败]
- **当前可选出路**：
  1. **缩小范围**：[先不做有冲突的某个小特性，保留主流程跑通]（耗时短，风险低）
  2. **换技术方案**：[放弃当前写法，换用另一条路径重新实现]（耗时中，需重新验证）
  3. **请人工协助**：[需要懂底层技术的人员进行 5 分钟定位]
  4. **暂缓搁置**：[先回滚至任务前还原点，继续推进其他独立模块]
- **Agent 推荐出路**：推荐出路 [1/2/3/4]，理由：[一句话理由]。
```

## 模板五：零基础可执行演示步骤 (Zero-Barrier Demo)
*适用场景：交付时的亲手跑通演示。*

```markdown
### 🕹️ PM 零基础演示步骤
1. **启动/打开**：双击打开 [文件名/快捷方式]（或终端直接运行复制：`单行命令`）；
2. **操作步骤**：点击界面上的 [具体按钮/区域]；
3. **预期效果**：你应该看到 [具体明确的视觉或文本变化，禁止写“功能正常”等废话]。
```
