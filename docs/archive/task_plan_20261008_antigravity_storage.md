## 一、 PM 白话验收标准 (5 条)
1. **防未关软件误伤**：运行搬迁前若反重力尚未彻底关闭，脚本能智能检测并强制阻断，杜绝数据损坏。
2. **数据完整不丢**：迁移后新磁盘（如 E 盘）中的配置、历史对话与工作区分支文件与原 C 盘文件完全一致。
3. **传送门无缝生效**：C 盘原目录建立系统级目录联接，反重力软件无感知，路径完全保持兼容。
4. **验证开机正常**：重新打开反重力软件后，历史对话、当前项目均可正常打开与对话，且 C 盘释放约 2GB 空间。
5. **提供安全后悔药**：迁移前原数据自动重命名为备份文件夹，绝不擅自删除；同时配备一键还原回退脚本。
