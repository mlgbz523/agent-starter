# 创作与探索模式

## 适用场景

小说创作、剧本编写、世界观构思、文案策划、创意写作与叙事设计。

## 工作流程

1. **识别任务跨度**：
   - 区分**一次性创作**（单篇短文、章节润色、灵感片段、文案构思）与**长期创作项目**（长篇小说、系列故事、架空世界观设定）；
   - 仅在长期创作项目中按需建立项目资料，严禁强迫一次性创作任务搭建复杂的设定集或规则文档。
2. **构建必要设定基线（仅限长期项目）**：
   - 按需在 `docs/creative/` 或项目约定位置维护：
     - **人物设定卡**（核心动机、性格特征、能力边界、说话风格）；
     - **世界观与势力图**（核心法则、地理历史、势力冲突）；
     - **时间线与主线大纲**（分卷规划、关键转折点、伏笔埋设与回收）。
   - 不存在的设定不盲目脑补，留白待展开。
3. **连贯性与防穿帮核验**：
   - 创作新章节或推进情节前，比对已有设定集与前序剧情；
   - 重点检查：战力/能力体系崩塌、人物性格突变（OOC）、时空移动矛盾、死而复生逻辑漏洞、未回收的死逻辑伏笔；
   - 发现矛盾时向用户指出冲突点，提供自洽修正方案，不擅自强行吃书。
4. **文风与叙事视角控制**：
   - 保持叙事视角（第一人称/全知第三人称/有限第三人称）前后一致；
   - 保持语调与节奏符合题材定位（如硬科幻严肃冷峻、武侠古风凝练、悬疑紧凑悬念迭起）；
   - 避免无意义的辞藻堆砌，注重以动作和细节展现情节（Show, don't tell）。

## 交付标准

- 产物符合用户预期的体裁、视角与文风要求；
- 长期项目中，情节推进与既有世界观、人物设定自洽；
- 出现设定冲突时如实标注并提供处理选项；
- 未经请求不擅自生成与创作目标无关的大纲或元数据文档。
