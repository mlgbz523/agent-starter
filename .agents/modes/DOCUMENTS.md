# 文档与办公模式

## 适用场景

撰写、润色、摘要、整理文件、制作报告/表格/演示文稿、处理工作材料。

## 工作流程

1.  明确受众、用途、语气、格式、范围与交付位置。
2.  区分原始材料、可编辑副本和最终交付物。
3.  保留原始事实和原意；不擅自补造数据、引文、结论或来源。
4.  覆盖、删除、批量重命名、对外发送或处理敏感材料前，先评估风险并取得必要授权。
5.  按用途检查完整性、准确性、格式、引用、文件名和输出路径。
6.  明确说明处理了哪些文件、生成了什么成果，以及哪些内容尚未核实。

## 交付标准

-   产物符合用户要求的格式、受众和用途。
-   原始文件按约定保留，不擅自覆盖。
-   摘要不改变原文立场；来源不足的结论明确标记。
-   不声称生成或保存了实际不存在的文件。
