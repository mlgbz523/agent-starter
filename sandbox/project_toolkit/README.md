# 磁盘运维与源头重定向工具箱 (project_toolkit)

> **定位**：专为 PM 与开发者设计的一站式 C 盘空间治理、源头重定向与安全防护工具集。已在 `sandbox` 目录下完全物理隔离。

---

## 📁 目录结构

```text
sandbox/project_toolkit/
├── 🚀 toolbox.bat                        <-- 【总控入口】双击即可唤起全功能中文交互菜单，一键直达所有功能
├── 📑 使用说明.md                         <-- 详细使用说明书与排错指南
├── 📑 README.md                          <-- 本说明文档
├── 01_antigravity/                       <-- 【模块一】反重力专属工具集（迁移/还原/工作树清理）
├── 02_c_drive_cleanup/                   <-- 【模块二】C 盘纯垃圾秒级急救清理（100% 保留系统休眠）
├── 03_permanent_redirection/             <-- 【模块三】一劳永逸源头重定向体系（分流至 D 盘）
└── 04_appdata_selective/                 <-- 【模块四】AppData 10 大常用应用定向搬迁
```

---

## 🚀 启动与使用方式

1. 鼠标双击打开 **`toolbox.bat`**；
2. 控制台会弹出清晰的中文数字菜单：
   - 输入 `1`：执行 C 盘纯垃圾秒级清理（立省 ~18 GB）；
   - 输入 `2`：执行一劳永逸源头重定向（立省 ~6.3 GB + 未来终身免疫）；
   - 输入 `3`：执行 AppData 10 大常用应用定向搬迁（立省 ~12 GB）；
   - 输入 `R1` / `R2` / `R3`：随时一键后悔药撤销还原。
