# Windows C 盘全能瘦身与源头重定向工具箱 (Toolbox) 使用说明文档

> **设计宗旨**：专为 PM 及广大开发者设计的一站式 C 盘空间治理、源头重定向与安全防护工具集。
> **核心原则**：绝不破坏 Windows 核心系统稳定性；所有重定向均配有一键安全撤销脚本；所有启动器均采用 100% 纯 ASCII 代码防乱码设计。

## 🌟 零门槛操作指南：如何使用？

### 推荐方式：双击总控入口（最简单）
1. 在 Windows 资源管理器中打开工具箱目录 [`E:\DiskCleanToolkit\`](file:///E:/DiskCleanToolkit/)（或在项目工程中直接双击 [`tools/打开磁盘工具箱.bat`](file:///E:/workSpace/planProject/tools/%E6%89%93%E5%BC%80%E7%A3%81%E7%9B%98%E5%B7%A5%E5%85%B7%E7%AE%B1.bat)）；
2. 鼠标双击打开 **`toolbox.bat`**；
3. 控制台会弹出清晰的中文数字菜单：
   - 输入 `1`：执行 C 盘纯垃圾秒级清理（立省 ~18 GB）；
   - 输入 `2`：执行一劳永逸源头重定向（立省 ~6.3 GB + 未来终身免疫）；
   - 输入 `3`：执行 AppData 10 大常用应用定向搬迁（立省 ~12 GB）；
   - 输入 `R1` / `R2` / `R3`：随时一键后悔药撤销还原。

### 独立运行方式：进入分类子目录
如果你只想运行某一项功能，也可以直接进入对应的子文件夹：
- 想清理垃圾：进入 `02_c_drive_cleanup\`，双击 `clean_c_drive_junk.bat`；
- 想装配源头重定向：进入 `03_permanent_redirection\`，双击 `setup_permanent_redirection.bat`；
- 想搬迁某个应用：进入 `04_appdata_selective\`，双击 `migrate_appdata_to_d.bat`。

## 📦 各功能模块详解

### 1. C 盘纯垃圾秒级清理 (`02_c_drive_cleanup\`)
- **包含清理项**：
  1. 25 款软件自更新留下的静默安装包（`AppData\Local\*-updater`，释放 4.19 GB）；
  2. Sandboxie 沙盒隔离临时运行文件（释放 3.65 GB）；
  3. 上一次反重力迁移留下的冷备份（`.gemini_backup`，释放 2.08 GB）；
  4. Windows 更新历史镜像暂存（`C:\$WinREAgent`，释放 1.75 GB）；
  5. npm-cache 与 Python uv 开发下载缓存（释放 1.60 GB）；
  6. 补齐微信/腾讯数据 D 盘传送门（释放 1.74 GB，QQ 退出后自动打通）；
  7. 迅雷自动更新包与旧驱动安装解压残余（`C:\AMD`，释放 1.31 GB）。
- **安全保障**：
  - **100% 完整保留系统休眠文件 (`hiberfil.sys`)**，休眠与断电保护完全不受任何影响；
  - 自动申请管理员权限以清除根目录更新镜像。

---

### 2. 一劳永逸源头重定向体系 (`03_permanent_redirection\`)
- **包含动作**：
  1. **卡死软件安装入口**：将 `AppData\Local\Programs` 搬迁至 `D:\Programs` 并打通传送门（释放 2.94 GB，**以后新装单用户软件即使点默认安装，全部自动落入 D 盘！**）；
  2. **卡死通用大缓存**：将 `C:\Users\15770\.cache` 搬迁至 `D:\.cache` 并打通传送门（释放 3.32 GB，Codex / Puppeteer 等浏览器镜像自动流向 D 盘）；
  3. **卡死开发与 AI 模型入口**：注入 6 大系统环境变量（`NPM_CONFIG_CACHE`、`PIP_CACHE_DIR`、`UV_CACHE_DIR`、`HF_HOME`、`TORCH_HOME`、`CARGO_HOME`），将依赖包与几十 GB AI 模型权重永久分流至 `D:\DevCache`；
  4. **系统设置联动**：自动拉起 Windows 原生【保存新内容的地方】，引导将应用默认安装盘设为 D 盘。
- **撤销方式**：双击 `rollback_permanent_redirection.bat`，几秒内即可安全拆除传送门并复原环境变量。

---

### 3. AppData 10 大应用定向搬迁 (`04_appdata_selective\`)
- **包含应用**：
  - Node NVM (2.11 GB)、腾讯应用 (1.74 GB)、Telegram Desktop (1.47 GB)、AdsPower (1.41 GB)、米哈游 (1.22 GB)、极限竞速地平线4 (1.20 GB)、QQ (0.84 GB)、网易云音乐 (0.84 GB)、B站直播姬 (0.73 GB)、ChatGPT 客户端 (0.65 GB)。
- **智能防冲突保护**：
  - 搬迁前自动检测进程（如检测到 QQ、Telegram 正在打开，会自动黄色提示并跳过该软件，绝不损坏正在使用的文件）。
- **撤销方式**：双击 `rollback_appdata_from_d.bat` 随时反向无损回拷。

---

### 4. 反重力专属工具集 (`01_antigravity\`)
- **包含功能**：
  - `migrate_gemini_storage.bat`：反重力 `.gemini` 数据目录搬迁至 E 盘（前期已执行，当前正常工作中）；
  - `prune_worktrees.bat`：日常项目工作树清理工具，自动注销已经关闭对话的历史会话分支，保持项目仓库干净轻量；
  - `rollback_gemini_storage.bat`：一键撤销 E 盘传送门并将数据迁回 C 盘。

## ⚠️ 常见疑问与排错指南 (FAQ)

1. **双击批处理时弹出黑窗口一闪而过或乱码怎么办？**
   - 当前所有 `.bat` 文件均已重构为 100% 纯 ASCII 代码，绝不会再发生 `cmd.exe` 中文识别错误；
   - 内部已加入编码自适应与 pause 暂停机制，执行完毕后会停留在屏幕上供你查看结果。
2. **弹出“是否允许应用对设备进行更改”的 UAC 弹窗怎么办？**
   - 点击**“是”**即可。清理 `C:\$WinREAgent` 和旧驱动解压目录需要 Windows 管理员权限，脚本已内置安全提权。
3. **搬迁某个软件时提示跳过怎么办？**
   - 说明该软件当前正在后台运行（例如 QQ 或 Telegram 没退出）。只需先退出该软件，再次运行即可成功搬迁。
