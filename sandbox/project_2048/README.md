# 样例工程 2：经典 2048 益智小游戏 (project_2048)

> **定位**：用于测试纯前端现代响应式 UI 渲染、方向键滑动合并状态机与单文件自包含应用的设计样例。

---

## 📁 目录结构

```text
sandbox/project_2048/
├── 🎮 index.html                 <-- 游戏完整单文件网页（可直接双击运行）
├── 🚀 start-demo.bat             <-- 本地 HTTP 预览启动器（8001 端口）
└── 📑 README.md                  <-- 本说明文档
```

---

## 🚀 启动与体验方式

1. **方式一（最简）**：直接在文件资源管理器中双击 `index.html`，无需安装任何依赖；
2. **方式二（本地服务器）**：双击 `start-demo.bat`，脚本将自动拉起 8001 端口并唤起默认浏览器打开游戏。

---

## 🎮 操作指引

- **方向键 (↑ / ↓ / ← / →)** 或 **触屏滑动**：移动滑块合并相同数字；
- 目标：合成 2048 格子！
